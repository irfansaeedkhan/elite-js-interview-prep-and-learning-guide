<TopicDefinition>

**React** models UI as a function of state. **Components** are the building blocks — each one returns a tree of **elements** describing what should appear on screen.

**JSX** is the syntax you write in `.jsx` files: it looks like HTML but compiles to `React.createElement(type, props, ...children)`.

</TopicDefinition>
