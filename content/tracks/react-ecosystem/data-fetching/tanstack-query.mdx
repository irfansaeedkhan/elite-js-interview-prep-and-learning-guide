  - Server state is async, shared, and needs caching — different from UI state
  - useQuery handles fetch, cache, stale time, and background refetch
  - Query keys identify cached data; invalidation triggers refetch
  - Redux is for client state; TanStack Query is for server/async state

interviewQuestions:
  - id: rq-1
    question: When would you choose TanStack Query over Redux?
    answer: When state comes from the server and you need caching, deduplication, background refetch, and stale-while-revalidate — not global UI state.
    difficulty: medium
  - id: rq-2
    question: What is a query key?
    answer: A serializable array that uniquely identifies cached query data. Changing the key creates a separate cache entry.
    difficulty: easy
