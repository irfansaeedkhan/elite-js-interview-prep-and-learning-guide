<CodingChallenge
  title="Prove a listener can be collected by dropping its reference"
  prompt="You cannot force garbage collection in this sandbox, and no test can observe it directly. What you CAN prove is the prerequisite: the last strong reference is gone. This exercise models that with a registry: a listener counts as retained while the registry holds it. Write subscribe and unsubscribe so that unsubscribing removes the listener from the registry. Only then is the listener eligible for collection; a forgotten unsubscribe is the classic leak."
  hint="Keep the registry as a plain array. Unsubscribe must remove exactly that function reference, in place, so every reader sees the same array."
  starterCode={`const registry = [];
function subscribe(fn) {
  // SUBSCRIBE
}
function unsubscribe(fn) {
  // UNSUB
}
function dispatch(value) {
  registry.forEach((fn) => fn(value));
}

let received = [];
function listener(value) { received.push(value); }`}
  tests={[
    { label: 'subscribe registers the listener', code: `subscribe(listener); if (registry.length !== 1) throw new Error('expected 1 registered listener, got ' + registry.length);` },
    { label: 'dispatch reaches the listener', code: `dispatch(7); if (received.length !== 1 || received[0] !== 7) throw new Error('expected listener called once with 7');` },
    { label: 'unsubscribe empties the registry', code: `unsubscribe(listener); if (registry.length !== 0) throw new Error('expected empty registry after unsubscribe, got ' + registry.length);` },
    { label: 'dispatch after unsubscribe calls nobody', code: `dispatch(8); if (received.length !== 1) throw new Error('expected no more calls after unsubscribe');` },
  ]}
