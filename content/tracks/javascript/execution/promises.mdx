  - id: prom-2
    question: What is the difference between Promise.all and Promise.allSettled?
    answer: Promise.all rejects immediately if any promise rejects. allSettled always waits and returns status for each.

<TopicDefinition>

A **Promise** is an object representing the eventual completion or failure of an asynchronous operation. Promises replace callback pyramids with **chainable** `.then` / `.catch` handlers.

Because `.then` schedules **microtasks**, Promise order questions almost always appear alongside the event loop.

</TopicDefinition>

<TopicTab value="examples">

<CodeExample title="Chaining" language="javascript">
{`Promise.resolve(1)
  .then((n) => n + 1)
  .then((n) => n * 2)
  .then(console.log); // 4`}
</CodeExample>

<CodeExample title="async/await" language="javascript">
{`async function fetchUser() {
  try {
    const res = await fetch('/api/user');
    return await res.json();
  } catch (err) {
    console.error(err);
  }
}`}
</CodeExample>

<TopicTab value="indepth">

<CodeExample title="Output order with setTimeout" language="javascript" runnable>
{`console.log('A');
setTimeout(() => console.log('B'), 0);
Promise.resolve().then(() => console.log('C'));
console.log('D');
// A, D, C, B`}
</CodeExample>
