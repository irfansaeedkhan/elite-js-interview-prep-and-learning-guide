<TopicDefinition>

If someone asks what a **string** is in JavaScript, I'd say it's how the language stores text — user names, error messages, JSON payloads, all of it. You create them with single quotes, double quotes, or backticks for templates.

Interviewers almost always follow up with **immutability**: you don't change a string in place. Methods like `trim()` or `replace()` return a **new** string. That's why trying `s[0] = 'H'` does nothing useful.

In senior rounds you might hear **UTF-16** — some characters (emoji) use two code units, so `"👋".length === 2`. Good to know; don't lead with it unless they go deep on Unicode.

</TopicDefinition>

{`console.log('5' + 3);   // '53'
console.log('5' - 3);   // 2

<CodeExample title="slice vs substring" language="javascript">
{`'hello'.slice(1, 3);     // 'el'
'hello'.slice(-3);        // 'llo' — negatives count from the end
'hello'.substring(1, 3);  // 'el'
'hello'.substring(-3);    // 'hello' — negatives treated as 0
'hello'.substring(3, 1);  // 'el' — arguments get swapped`}
</CodeExample>

<Callout type="interview">
When you see `+` with mixed types, say **"string concatenation wins if either side is a string."**

<CodeExample title="Surrogate pairs" language="javascript">
{`'👋'.length;             // 2 — one emoji, two UTF-16 code units
'👋'.split('').length;   // 2 — split breaks the pair
Array.from('👋').length; // 1 — iterates code points
[...'👋👋'].length;       // 2 — spread uses code points too`}
</CodeExample>

### Useful methods

- `includes(sub)` — boolean search
- `startsWith` / `endsWith` — prefix/suffix checks
- `slice(start, end)` — extract substring (supports negatives)
- `replace` / `replaceAll` — replace matches
