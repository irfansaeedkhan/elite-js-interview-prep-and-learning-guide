<TopicDefinition>

An **array** is an ordered list backed by an object with a `length` property. JavaScript arrays are **dynamic** — you can push, pop, and sparse gaps are allowed.

Senior interviews focus on **immutability vs mutation** and choosing the right iteration method.

</TopicDefinition>

<TopicTab value="examples">

<CodeExample title="Functional transforms" language="javascript">
{`const nums = [1, 2, 3, 4];

const doubled = nums.map((n) => n * 2);
const evens = nums.filter((n) => n % 2 === 0);
const sum = nums.reduce((acc, n) => acc + n, 0);

console.log(doubled); // [2, 4, 6, 8]
console.log(evens);   // [2, 4]
console.log(sum);     // 10`}
</CodeExample>

<CodeExample title="Mutating vs non-mutating" language="javascript">
{`const original = [1, 2, 3];
const copy = [...original];
copy.push(4);

console.log(original); // [1, 2, 3]
console.log(copy);     // [1, 2, 3, 4]`}
</CodeExample>

</TopicTab>

<TopicTab value="indepth">

<Callout type="gotcha">
`sort()` without a comparator coerces elements to strings — `[10, 2, 1].sort()` becomes `[1, 10, 2]`.
</Callout>

<CodeExample title="Correct numeric sort" language="javascript">
{`[10, 2, 1].sort((a, b) => a - b); // [1, 2, 10]`}
</CodeExample>
