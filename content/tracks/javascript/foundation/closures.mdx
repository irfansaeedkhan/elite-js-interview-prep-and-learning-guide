    answer: A closure is created when a function references variables from an outer scope. The inner function keeps those bindings alive even after the outer function finishes.

<TopicDefinition>

A **closure** forms when a function is defined inside another function and **remembers** variables from the outer scope — even after the outer function has returned.

Closures are the mechanism behind **encapsulation** in JavaScript without classes.

</TopicDefinition>

<TopicTab value="examples">

<CodeExample title="Private counter" language="javascript">
{`function createCounter() {
  let count = 0;
  return {
    increment() { count += 1; return count; },
    getCount() { return count; },
  };
}

const counter = createCounter();
counter.increment();
console.log(counter.getCount()); // 1`}
</CodeExample>

<CodeExample title="Loop trap with let" language="javascript">
{`for (let i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 0);
}
// 0, 1, 2 — each iteration gets its own i binding`}
</CodeExample>
