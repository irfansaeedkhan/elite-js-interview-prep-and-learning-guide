    answer: When a property is missing on an object, JavaScript looks up the internal prototype link, then that object's prototype, until null.

  - id: proto-2
    question: What is the difference between __proto__ and prototype?
    answer: prototype is on constructor functions and becomes the internal prototype of instances. __proto__ is the instance's link to its prototype (legacy accessor).
    difficulty: hard

<TopicDefinition>

JavaScript uses **prototypal inheritance**: objects delegate property lookups to another object via an internal link. There is no classical copying of class blueprints — objects **link** to shared prototypes.

</TopicDefinition>

<TopicTab value="examples">

<CodeExample title="Prototype lookup" language="javascript">
{`const animal = { eats: true };
const rabbit = Object.create(animal);
rabbit.jumps = true;

console.log(rabbit.eats);  // true — found on prototype
console.log(rabbit.jumps); // true — own property`}
</CodeExample>

<CodeExample title="Constructor pattern" language="javascript">
{`function Person(name) {
  this.name = name;
}
Person.prototype.greet = function () {
  return \`Hi, \${this.name}\`;
};

const ada = new Person('Ada');
console.log(ada.greet()); // Hi, Ada`}
</CodeExample>
