<TopicDefinition>

**Hoisting** is JavaScript's behavior of processing declarations during the **compilation phase** before running code line by line. It explains why you can sometimes call a function before its declaration — and why `let` before declaration throws.

</TopicDefinition>

<TopicTab value="examples">

<CodeExample title="var vs let" language="javascript">
{`console.log(a); // undefined
var a = 1;

try {
  console.log(b);
} catch (e) {
  console.log(e.name); // ReferenceError
}
let b = 2;`}
</CodeExample>

<CodeExample title="Function declaration hoisting" language="javascript">
{`greet(); // works

function greet() {
  console.log('Hello');
}`}
</CodeExample>

<TopicTab value="indepth">

<Callout type="gotcha">
`const fn = function() {}` is **not** hoisted as a callable function — only the `fn` binding is hoisted if declared with var (as undefined).
</Callout>

### Temporal Dead Zone (TDZ)

From scope entry until `let`/`const` initialization, the binding exists but cannot be accessed.
