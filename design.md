# Design direction

Art direction for UI and landing pages. Token values live in `src/app/globals.css`.

**Canonical reference:** [DESIGN-ETHICS.md](./DESIGN-ETHICS.md) (calm, premium, Sunsama inspired discipline).

**Brand copy:** [BRAND.md](./BRAND.md)

**Rules:**
- One primary CTA per section
- Generous whitespace, readable type scale
- `rounded-xl` inputs, `rounded-full` primary buttons, `rounded-3xl` marketing cards
- No neon gradients or dense icon grids
- Product screenshots over stock illustrations on landing pages

Develop skill owns updates to this file when visual language changes.
